03 / Deliberate boundaries

No cloud account, server, external model, package install or network request is needed to open this file and query the embedded sample. Everything is synthetic. SHA-256 detects changed bytes when the hash is held fixed; it does not prove authorship, source truth or tamper-resistance against an adversary who can replace both the data and its declared hashes.
