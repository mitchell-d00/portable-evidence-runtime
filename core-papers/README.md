# Core papers

The supplied archive contains one research manuscript. This directory provides
the revised manuscript and a separate engineering review, each in Markdown,
plain text, and PDF.

| Document | Markdown source | Plain text | PDF |
|---|---|---|---|
| Portable Evidence Runtime, v0.2 | [MD](Portable_Evidence_Runtime.md) | [TXT](Portable_Evidence_Runtime.txt) | [PDF](Portable_Evidence_Runtime.pdf) |
| Validation and Publication Review | [MD](Validation_and_Publication_Review.md) | [TXT](Validation_and_Publication_Review.txt) | [PDF](Validation_and_Publication_Review.pdf) |

Edit the Markdown sources here, then run `sh scripts/build_paper.sh` from the
repository root. The script also updates the manuscript copies in `paper/`.
Build tools: Pandoc, XeLaTeX, and DejaVu fonts. Reading the finished documents
requires none of those tools.

The manuscript is suitable for public discussion as a bounded prototype preprint.
It has not been peer reviewed or independently validated. The review records
remaining evidence and licensing limits without inventing additional papers.
